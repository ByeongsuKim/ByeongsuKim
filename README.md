## 🔬 지금 만들고 있는 것

### RhythmTalk — 속화증(Cluttering) 진단·연습 앱

말이 지나치게 빠르거나 불규칙해지는 **속화증**을 위한 안드로이드 앱입니다.
말더듬과 달리 널리 알려져 있지 않아, 자신이 해당되는지조차 모르는 경우가 많습니다.

한 연구에서 속화 특성을 자기보고한 사람 중 **실제로 언어치료를 받은 사람은 21%뿐**이었습니다.
문제는 치료법이 없는 것이 아니라 치료에 도달하지 못하는 것이었습니다.

- 1900년부터 현재까지 국제 문헌 **260여 건**을 직접 정리해 설계 근거로 삼았습니다
- 말속도뿐 아니라 **리듬 불규칙성**을 함께 측정합니다 — 최근 연구는 리듬이 더 유효한 지표일 수 있다고 봅니다
- 한국어권에는 속화증 단독 연구가 거의 없어, 규준 데이터를 함께 쌓는 것을 목표로 합니다

> 🚧 비공개 개발 중 · Kotlin · Jetpack Compose · 온디바이스 음향 분석
